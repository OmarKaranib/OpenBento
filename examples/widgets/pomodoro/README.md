# Pomodoro — Sample OpenBento Custom Widget

A tiny ~150-line standalone HTML page that demonstrates the OpenBento
Widget SDK end-to-end: `ready`, `getState`, `setState` round-trip, and the
theme bridge.

The shipped, server-served copy lives at
`client/public/examples/widgets/pomodoro/index.html` so it's reachable at
`/examples/widgets/pomodoro/index.html` from the dashboard. The "Custom
Widget" Block Library entry exposes it as the **Pomodoro Timer** sample.

See `/dev/widgets` in the running app for the full SDK contract.
